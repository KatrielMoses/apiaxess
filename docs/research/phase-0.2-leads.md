# Phase 0.2 research leads

These references were verified as context, not adopted as model authorities.

- Baazizi, Colazzo, Ghelli, and Sartiani, [A Type System for Interactive JSON
  Schema Inference](https://doi.org/10.4230/LIPIcs.ICALP.2019.101), ICALP 2019.
  The paper confirms work on JSON type inference at selectable levels of
  precision. APIaxess does not import its type system or inferencer.
- Akita's [2023 acquisition announcement](https://www.akitasoftware.com/blog-posts/announcing-akita-has-joined-postman)
  confirms that Akita joined Postman. Current official [Postman Insights
  documentation](https://learning.postman.com/docs/insights/overview/) describes
  a traffic-watching agent that automatically infers endpoints. This validates
  the prior-art category, not a compatible data model or export contract.
